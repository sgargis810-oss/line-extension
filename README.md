This is a simple line reader extension made by Vinudhi and Gargi.
It is customizable, easy to use, and perfect for college or high school students that have 
to do a lot of reading!

Steps for USE:
(1) open chrome extensions
(2) click load unpacked, and select this proect
(3) open any webpage and use the yellow highlight bar, you can use the color picker to change color
(4) HAVE FUN!
